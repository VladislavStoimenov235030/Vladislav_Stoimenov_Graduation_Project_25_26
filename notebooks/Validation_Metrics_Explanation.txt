This is the important part for evaluation.

YOLO is testing the model on your validation set, not training set. Ultralytics uses precision, recall, mAP50, and mAP50-95 as core object-detection validation metrics.

Class

This means the metric is averaged over all classes.

Later YOLO may also print separate rows for each class.

Images

This means the validation set contains 60 images.

This means those 60 validation images contain 161 total labeled damage objects.

So one image can contain more than one damage.

Box(P) / Precision

Precision means:

Of all boxes the model predicted, how many were actually correct?

High precision = fewer false detections.

Example:

Box(P) = 0.233

This means around 23.3% of predicted detections were correct.

Low precision means the model is producing many wrong detections.

R / Recall

Recall means:

Of all real damage objects, how many did the model find?

High recall = fewer missed damages.

Example:

R = 0.149

This means the model found around 14.9% of the real damage objects.

Low recall means the model is missing many damages.

mAP50

This means mean Average Precision at IoU threshold 0.50.

In simple words:

How good are the detections if predicted boxes need to overlap real boxes by at least 50%?

Higher is better.

Example:

mAP50 = 0.052

That means performance is still low, but this is normal in the first few epochs, especially with a small dataset.

mAP50-95

This is stricter than mAP50.

It averages performance across multiple IoU thresholds from 0.50 to 0.95.

So it checks not only whether the model roughly finds the damage, but also whether the box is very accurately placed.

Example:

mAP50-95 = 0.0217

This will usually be much lower than mAP50.
